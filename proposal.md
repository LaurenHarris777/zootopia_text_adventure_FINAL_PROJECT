## Title:
Zootopia: Wildest Hops

## Repository:

https://github.com/LaurenHarris777/zootopia_wildest_hops_FINAL_PROJECT

## Description:

ZPD Officers Wilde and Hopps are back in pursuit! This platform game will take place in the world of Zootopia. Play as both Judy Hopps and Nick Wilde to complete multiple levels with collectibles, enemies and a new case to crack.

## Features:
- Feature 1:
	- Original sprite artwork for characters, backgrounds and items.
- Feature 2:
	- Save points for game progress.
- Feature 3:
	- Collect-a-thon type gameplay where certain items must be collected to complete the level.
- Feature 4:
	- Gameplay switches between two avatars (Judy Hopps and Nick Wilde) depending on the level.

## Challenges:
- Successfully integrating sprite artwork into the game.
- Creating functions for different objects in the game (player avatar, enemies, items, etc.)
- Learning capabilities of the Pygame library beyond what was used in the course materials.
- Finishing a playable game by the project deadline (scope creep vs time constraints).

## Outcome:
- Ideal Outcome: A fun and engaging game that can keep players busy and make them want to back and play again.

- Minimal Viable Outcome: A game that runs successfully and utilizes the characters and other sprites created. If the goal of 3 levels cannot be met in time for the deadline, then the game most at least have 1 level that the user can complete to win.

## Milestones:
- Week 1: create skeleton of game (pseudocode), start working on spritework.
- Week 2: complete sprites and load them into the game. Have code roughly complete (possibly with some bugs/glitches)
- Final Week: completed, playable project commited to GitHub repository (along with a recorded demonstration/demo).
