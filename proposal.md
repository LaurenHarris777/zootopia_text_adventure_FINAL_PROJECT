## Title:
A Zootopia Text Adventure

## Repository:

https://github.com/LaurenHarris777/zootopia_text_adventure_FINAL_PROJECT

## Description:

This text-based game will let you create your own character and join the Zootopia Police Department with officers Judy Hopps and Nick Wilde. In this game, you will choose your own path and ultimately use your detective skills to solve a case!

## Features:
- Feature 1:
	- Create an original character (from a select number of different animals).
- Feature 2:
	- Save points for game progress.
- Feature 3:
	- Multiple story paths/choose your own adventure format.
- Feature 4:
	- Inventory system for holding evidence.

## Challenges:
- Managing a story with multiple branches efficiently.
- Creating an intriguing story.
- Making an inventory system that works for storing important items.
- Scope creep vs time constraints.

## Outcome:
- Ideal Outcome:
	- A fun and engaging game that can keep players busy and make them want to go through and try to get all of the endings. The initial goal is to have at least 10-15 minutes of gameplay per story, and 3-4 stories in total.
- Minimal Viable Outcome:
	- A functional text-based game that includes all of the core features listed in this proposal document.

## Milestones:
- Week 1: Map out basic story tree (branches for different story paths) and implement basic functions for the code (character creation, inventory, etc.).
- Week 2: Roughly mapped out code, hopefully nearly ready to submit but possibly with bugs/errors.
- Final Week: Finished Project.
